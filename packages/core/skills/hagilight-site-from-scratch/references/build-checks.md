# Build checks

Run the production build, then check the files the site type generates. The file list depends on the site type, so use the list for your type. A file the list names but the build does not write is a failed check.

Run these checks on the built output, not on the source:

- Sitemap URLs use the site's own `https://` origin. For example, `grep -c '<loc>http://' dist/sitemap-*.xml` should print nothing.
- `robots.txt`, when present, names the sitemap with an absolute URL.
- Feeds exist for the locales that have items.

## Plain Astro (`hagilight()`)

The integration writes these into the output directory when the site URL is set:

- `sitemap-index.xml` and its sitemap pages. Skipped when the site already provides a sitemap.
- `robots.txt`. Skipped when the site already provides one.
- `rss.xml` and `rss.<language>.xml`, one per locale. On by default; `rss: false` turns them off.
- `llms.txt`, written from the built pages. Skipped with a warning when no page is indexable, and left alone when the site ships its own.
- `.well-known/hagilight.metadata.json`, written last, after the sitemap and `llms.txt`.

## Documentation, Starlight

The plugin writes these into the output directory:

- `sitemap-index.xml`, generated by Starlight's own sitemap.
- `rss.xml` and `rss.<language>.xml`, one per locale. On by default; `rss: { enabled: false }` turns them off.
- `.well-known/hagilight.metadata.json`, written once per build, after the sitemap, so it lists the sitemap and any feed that exists.

The Starlight plugin writes no `robots.txt` and no `llms.txt`. If the site needs a `robots.txt`, add it to `public/` and check it yourself.

## Documentation, Docusaurus

The plugin writes these, and only in the builds listed:

- `sitemap.xml`, into each locale's output, in production builds. Written only when the official `docusaurus-plugin-sitemap` is not loaded, and not when `noIndex` is set.
- `robots.txt`, written by the default-locale build only. It names one sitemap per locale, so build every locale (run `docusaurus build` without `--locale`) for the full list.
- `rss.xml`, per locale, when that locale has feed items.
- `.well-known/hagilight.metadata.json`, written by the default-locale build.

On GitHub Pages, publish a `.nojekyll` file at the root. Without it, the `.well-known` directory is dropped.
