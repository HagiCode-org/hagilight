Mermaid diagrams

One sample for each diagram type that Mermaid 11.16.1 registers, rendered by@hagicode/hagilight-mermaid. Each diagram reveals itself in the order its type reads. Hover a part to follow it through the diagram, or click a tile to enlarge it.

Mode
Preset

In the enlarged view: scroll to zoom, drag to move, 0 fits, 1 shows actual size, Esc closes.

sequenceDiagram
  autonumber
  participant U as User
  participant W as Web
  participant A as API
  participant D as Database
  U->>W: Open page
  W->>A: GET /pages
  loop every refresh
    A->>D: query
    D-->>A: rows
  end
  alt cache hit
    A-->>W: cached
  else cache miss
    A->>D: fetch
    D-->>A: result
    A-->>W: fresh
  end
  opt error
    A--xW: failed
  end
  Note over W,A: rendered in place
  par notify
    W-->>U: show
  and log
    A->>A: write log
  end
