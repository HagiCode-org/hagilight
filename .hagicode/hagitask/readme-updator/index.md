# README requirements

## Audience and focus

- Address developers who consume or maintain the published npm packages `@hagicode/hagilight`, `@hagicode/hagilight-core`, `@hagicode/hagilight-starlight` and `@hagicode/hagilight-docusaurus` for HagiCode sites.
- Open with the package set, what each package provides and the package badges.

## Required content

- Keep one section per package, plus PostHog analytics, first-party links and campaign tags, Google Analytics click events, TypeScript usage, local development, sitemap and robots.txt, localized RSS and the desktop viewport baseline, as the current README does.
- Ground usage examples in the package manifests and the `examples/` directory.

## Exclusions

- Exclude analytics keys, tokens, secret values, internal hosts, machine-specific paths and private links.
- Do not describe components or options the packages do not export.
