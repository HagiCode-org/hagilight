# Introduction

Hagilight for Docusaurus adds the HagiCode site features to a Docusaurus 3 site with one plugin entry:

```js
// docusaurus.config.ts
plugins: [hagilightDocusaurus()],
```

Every feature is on by default. See [Features](./features) for what each one does and [Options](./options) for every switch.
