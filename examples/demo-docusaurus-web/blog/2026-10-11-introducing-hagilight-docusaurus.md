Hagilight for Docusaurus brings the same site features that HagiCode sites already use to Docusaurus 3. Add one plugin entry and every feature is on, with each one available as its own switch.

This demo site exercises every feature. Its build output includes a sitemap and an RSS feed for each locale, and a `robots.txt` at the root that lists them.
