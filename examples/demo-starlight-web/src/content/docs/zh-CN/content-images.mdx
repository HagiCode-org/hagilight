本页展示 `@hagicode/hagilight-starlight` 自动应用的正文图片基线。

位于 `<picture>` 元素之外的 Markdown 与 MDX 图片会获得 `loading="lazy"`、`decoding="async"` 和 `hagilight-content-image` 类名。作者已经设置的值会保留，类名只会添加一次。
