This page shows the body-image baseline that `@hagicode/hagilight-starlight` applies automatically.

Markdown and MDX images outside a `<picture>` element get `loading="lazy"`, `decoding="async"`, and the `hagilight-content-image` class. Values the author already set are kept, and the class is added once.
