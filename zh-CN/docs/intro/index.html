简介

Hagilight for Docusaurus 只需添加一个插件配置，即可为 Docusaurus 3 站点加入 HagiCode 站点功能：

// docusaurus.config.ts
plugins: [hagilightDocusaurus()],

默认启用全部功能。各项功能的说明见功能，全部选项见选项。

功能

让想法变成真正交付的软件。

HagiCode 是面向项目开发的 AI 编码工作台：用 OpenSpec 工作流规划变更，多 Agent 并行执行，再由 Hero Scenario 让进度一目了然，把想法变成真正交付的软件。
