Introduction

Hagilight for Docusaurus adds the HagiCode site features to a Docusaurus 3 site with one plugin entry:

// docusaurus.config.ts
plugins: [hagilightDocusaurus()],

Every feature is on by default. See Features for what each one does and Options for every switch.

Features

アイデアを、出荷できるソフトウェアへ。

HagiCode はエージェント型コーディングワークスペースです。OpenSpec ワークフローで変更を計画し、マルチエージェント実行で進め、Hero Scenario で長い作業の進み具合を見える化して、アイデアを出荷できるソフトウェアにします。

HagiCode をダウンロード製品ドキュメント
スマート
OpenSpec ワークフローが、意図を提案からリリースまでの実行可能な道筋にします。
効率的
マルチエージェント実行で、調査・実装・レビューを並行して進めます。
楽しい
使いやすい UI で、計画・Agent 実行・プロジェクト作業を進めやすくします。
